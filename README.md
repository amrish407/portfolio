## 🛠️ Tech Stack & Analytical Focus

* **Core Web:** Semantic HTML5, Modern CSS3 (CSS Variables, Flexbox, Grid), Vanilla JavaScript (Intersection Observer API)
* **Data Analytics & BI:** Power BI (DAX, Star Schema, Power Query), Advanced Excel, Google Sheets
* **Databases & Cloud:** SQL (PostgreSQL, MySQL, T-SQL), AWS Athena, AWS S3, AWS Glue
* **Programming & Tools:** Python (Pandas, NumPy, Scikit-learn), C++, Git, GitHub, VS Code

## 📊 Highlighted Analytics Case Studies

1. **Marketing Campaign Performance & ROI Optimization:** Reconciled $42.54M revenue and $25.69M spend across 1,000 campaigns; audited source calculation discrepancies; calculated true spend-weighted net ROI (65.56%). *(Power BI, MySQL, DAX, Excel)*
2. **End-to-End Credit Card Fraud Analytics:** High-volume transaction analysis (283K+ rows) with deep EDA, XGBoost, SHAP explainability, and low-latency FastAPI scoring console. *(Python, SQL, XGBoost, SHAP, Streamlit)*
3. **Seasonal Inventory Management & Stockout Risk:** Analyzed 15.7K weekly records across 20 SKUs and 5 stores; developed dynamic safety stock and reorder point models in DAX. *(Power BI, DAX, Inventory Analytics)*
4. **HR Workforce Analytics & Employee Turnover:** Analyzed 22,000+ employee records in PostgreSQL to automate attrition rates, tenure cohorts, and demographic metrics in Power BI. *(PostgreSQL, Power BI, SQL)*

## 💻 Local Development

No complex build steps or dependencies required. Run a local HTTP server:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
