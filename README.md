# Amrish Yadav — Data Analyst Portfolio

A responsive, static portfolio site built with plain HTML, CSS and JavaScript. There is no build step or package installation.

## Run locally

Open `index.html` in a browser, or run a local server from this folder:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — portfolio content and project links
- `styles.css` — responsive layout and visual styling
- `script.js` — section reveals, active navigation and mobile menu
- `resume.pdf` — downloadable resume

## Host it

Any static host can serve this folder as-is. For a free hosted address, publish with GitHub Pages, Netlify or Vercel; each provides a service subdomain, so you do not need to buy a custom domain first. Upload or connect the repository root, and leave the build command and publish directory settings empty/default as appropriate for the host.

The site links to the public GitHub profile and project repositories. No hosting account, custom domain or deployment configuration is included in this folder.
